# X Analytics Tool

X(Twitter) のツイート分析を行う Google Apps Script ツールです。複数アカウントに対応し、月別にデータを管理します。

## 機能

- 複数アカウントのツイートデータを自動取得
- アカウント×月ごとにシートを自動作成
- インプレッション、いいね、RT、リプライ数を記録
- フォロワー数の推移を追跡
- プロフィールクリック率・フォロー率の判定

## セットアップ

### 1. Google スプレッドシートの準備

1. 新しい Google スプレッドシートを作成
2. メニュー「拡張機能」→「Apps Script」を開く
3. このリポジトリのコードをコピー、または clasp で push

### 2. clasp を使う場合

```bash
# clasp をインストール
npm install -g @google/clasp

# ログイン
clasp login

# .clasp.json の scriptId を自分のプロジェクトIDに変更
# プロジェクトIDは Apps Script エディタの URL から取得

# push
clasp push
```

### 3. Bearer Token の設定

1. [X Developer Portal](https://developer.twitter.com/) でアプリを作成
2. Bearer Token を取得
3. Apps Script で「プロジェクトの設定」→「スクリプト プロパティ」
4. プロパティ `BEARER_TOKEN` に Bearer Token を設定

### 4. 初期化

1. Apps Script エディタで `initialize` 関数を実行
2. 「マニュアル」シートと「設定」シートが作成されます

### 5. 対象アカウントの設定

1. 「設定」シートを開く
2. A列にユーザー名を入力（@なし、1行1アカウント）

```
A1: 対象ユーザー名（@なし）
A2: account1
A3: account2
A4: account3
```

### 6. 自動実行トリガーの設定（任意）

1. Apps Script で「トリガー」を開く
2. 「トリガーを追加」をクリック
3. 関数: `dailyFetch`
4. イベントのソース: 時間主導型
5. 時間ベースのトリガーのタイプ: 日付ベースのタイマー

## 使い方

### 実行関数

| 関数 | 説明 |
|------|------|
| `initialize` | 初期設定（マニュアル・設定シートを作成） |
| `initialFetch` | 過去7日分のツイートを取得（初回データ取得用） |
| `dailyFetch` | 過去24時間のツイートを取得（毎日実行用） |
| `manualFetch` | dailyFetch と同じ（手動テスト用） |
| `recalculateMetrics` | プロクリ率・フォロー率を再計算 |
| `setBearerToken` | ダイアログから Bearer Token を設定 |

### シート構成

- **マニュアル**: 使い方の説明
- **設定**: 対象アカウントを記載
- **{アカウント名}_{YYYY-MM}**: 月別のツイートデータ
  - 例: `satochin_2024-12`, `satochin_2025-01`

### データ列

| 列 | 内容 |
|----|------|
| 日付 | ツイート投稿日 |
| 種類 | 手動入力（通常/企画/引用RT など） |
| ツイート本文 | ツイートの内容 |
| インプ数 | インプレッション数 |
| いいね数 | いいねの数 |
| プロフクリック数 | プロフィールクリック数（※手動入力） |
| 詳細クリック | 詳細クリック数（※手動入力） |
| プロクリ率 | プロフクリック数 ÷ インプ数 |
| プロクリ判定 | ◎5%以上 / ○3%以上 / △2%以上 / ✕2%未満 |
| RT数 | リツイート数 |
| リプ数 | リプライ数 |
| リプした数 | 手動入力 |
| フォロワー数 | 取得時点のフォロワー数 |
| フォロー率 | フォロワー増加数 ÷ プロフクリック数 |
| フォロー率判定 | ◎3%以上 / ○2%以上 / △1%以上 / ✕1%未満 |
| フォロワー増加数（日） | 前日からの増加数 |
| フォロワー増加数（週） | 7日前からの増加数 |
| ツイートURL | ツイートへのリンク |

## 注意事項

- プロフクリック数と詳細クリック数は X API v2 では取得できません
- 正確な値が必要な場合は、X Analytics から手動で入力してください
- 手動入力後に `recalculateMetrics` を実行すると判定が再計算されます
- API制限があるため、多数のアカウントを登録する場合は注意してください
